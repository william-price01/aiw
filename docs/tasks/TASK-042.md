## TASK-042: Canvas packaging and local serve

Type: IMPLEMENTATION
Depends_on: [TASK-041]

Objective:
Bundle the React frontend static assets into the Python package, wire the FastAPI backend as the
local HTTP server, add `aiw canvas` as a CLI command that starts the server and opens the
browser, and ensure the full canvas is launchable with a single command from any
AIW-initialized repo.

Context (spec refs):
- PRD §15.4 (constraints: `aiw canvas` single-command launch)
- SDD §19.4 (Canvas launch)
- SDD §19.5 (technology constraints: FastAPI + uvicorn, static assets at `aiw/canvas/static/`)

Inputs:
- `aiw/canvas/frontend/dist/` (built static assets from TASK-041)
- `aiw/canvas/server.py` (FastAPI app from TASK-040)
- `aiw/cli/main.py` (CLI router — add `canvas` command)

Outputs (artifacts/files created or changed):
- `aiw/canvas/static/` (bundled frontend assets, checked into repo or generated by build step)
- `aiw/canvas/serve.py` (uvicorn launch logic + static file serving)
- `aiw/cli/canvas_cmd.py` (CLI command handler)
- `aiw/cli/main.py` (add `canvas` to dispatch table)

Interfaces/contracts:

`aiw/canvas/serve.py`:
- `start_canvas(root: Path, port: int = 7842, open_browser: bool = True) -> None`
  - Validates `.aiw/` exists in `root`; raises `CanvasError` if not.
  - Mounts `aiw/canvas/static/` as FastAPI static file mount at `/`.
  - Mounts `aiw/canvas/server.py` FastAPI app at `/api`.
  - Starts uvicorn on `127.0.0.1:{port}`.
  - If `open_browser`: calls `webbrowser.open(f"http://localhost:{port}")` after a 0.5s delay.
  - Runs until SIGINT (Ctrl-C).

`aiw/cli/canvas_cmd.py`:
- `canvas_command(root: Path, port: int = 7842) -> None`
  - Calls `start_canvas(root, port)`.

`aiw/cli/main.py` extension:
- Add `canvas` to the dispatch table.
- Argument: `--port` (optional, default 7842).
- Help: `Start the Canvas local web interface.`

Static asset packaging:
- Frontend `dist/` assets are copied to `aiw/canvas/static/` as part of the build/packaging step.
- `pyproject.toml` must include `aiw/canvas/static/**` in `package_data` so assets are included in the installed package.
- For development: `aiw/canvas/static/` may be populated by running `npm run build` in `aiw/canvas/frontend/` and copying `dist/` contents to `static/`.
- A `Makefile` target or `build.sh` script documents the build-and-copy step.

`pyproject.toml` additions:
- `fastapi>=0.110.0`
- `uvicorn[standard]>=0.29.0`
- `python-multipart` (for form body parsing in FastAPI)
- Frontend build dependencies remain in `aiw/canvas/frontend/package.json` only; not Python deps.

`tests/test_canvas_serve.py`:
- Tests that `start_canvas` raises `CanvasError` when `.aiw/` does not exist.
- Tests that the FastAPI app serves `GET /api/state` correctly when invoked via `TestClient`.
- Tests that `GET /` serves `index.html` from static mount (with mock static dir).
- Tests that `aiw canvas --help` exits code 0 and includes expected help text.

Constraints enforced:
- Server binds to 127.0.0.1 only (inherited from TASK-040 server).
- `aiw canvas` refused if `.aiw/` does not exist in current directory.
- No external services required at runtime.
- Static assets must be resolvable from the installed package (i.e., `importlib.resources` or `__file__`-relative path).

Non-goals:
- No hot-reload for frontend development (development workflow uses `npm run dev` separately).
- No HTTPS/TLS.
- No process daemonization.
- No port conflict resolution (fails with clear error if port is in use).

Acceptance criteria (measurable):
1. `aiw canvas` in an AIW-initialized repo starts the server and prints `Canvas running at http://localhost:7842`.
2. `aiw canvas` outside an AIW repo (no `.aiw/`) exits code 1 with error message.
3. `GET http://localhost:7842/` serves `index.html` (verified in test with TestClient).
4. `GET http://localhost:7842/api/state` returns workflow state JSON (via TestClient).
5. `aiw canvas --port 8080` starts on port 8080.
6. `aiw canvas --help` exits code 0 and shows help text.
7. `pip install -e .` in a clean environment makes `aiw canvas` available without separate frontend build step (static assets pre-bundled).
8. `tests/test_canvas_serve.py` passes.
